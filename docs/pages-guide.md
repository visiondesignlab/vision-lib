# Vision Lib 使用说明

Vision Lib 收录视频案例、灵感、平面作品、品牌 Skill、Skill 仓库与品牌资产。

- 点击卡片查看视频、来源、相关资料与复现提示词。视频静音自动播放并循环，可在播放器内打开声音。
- 点击“一键拉片”选择自己电脑上的 Codex、Cursor 或 Claude Code。网站预填提示词，由你确认发送；也可只复制提示词。所选工具会保存在当前浏览器。
- 搜索、分类和排序用于筛选内容。手机端通过顶部菜单切换栏目。
- 图片切图在浏览器中完成，图片不会上传服务器；支持切片及 ZIP 下载。
- 品牌资产支持图片/PDF 预览、缩放与下载。
- 网站尊重系统的“减少动态效果”设置。

此 GitHub Pages 版本展示已发布内容。内容管理、审核与导入在本机完成，重新发布后同步到网站；网站不提供在线拉片运算或管理员登录。
